# Simple Interest Calculator

Given:
P = 10,000 (principal)
R = 5% (interest rate)
T = 3 years (time)

Substitute the values into the formula
A = 10,000(1 + (5 / 100) * 3)

Calculate the interest
A = 10,000(1 + 0.15)

Add 1 and 0.15
A = 10,000(1.15)

Multiply
A = 11,500

So, the total amount A is 11,500.
